# A Repository of DMOJ Solutions

This is a short repository to some of my solutions to questions on the Don Mills Online Judge. Includes solutions from CCC (see README for that project), BlueBook, CCO, IOI, NOI, Baltic OI, etc.
It also includes solutions to troll problems / DMOJ lore problems which are usually worth only 0-3 points, but useful to know the 'secret'.
I plan to keep updating this repository with more solutions as time goes on.
