O(1)

Very Easy

### **CCC 20 S3 – Searching for Strings (ccc20s3)**

**Time complexity**

O(n + m)

**Space complexity**

O(1) for counts, O(m) for hash set

**Difficulty**

Hard

**All DMOJ subtasks accepted in:**
