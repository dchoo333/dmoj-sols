# 2014 CCC Report

---

### **CCC 14 J1 – Triangle Times (ccc14j1)**

**Main idea / algorithm**

Classify a triangle by its angles: equilateral, isosceles, scalene, or invalid if the angles do not sum to 180 or any angle is zero.

**Time complexity**

O(1)

**Space complexity**

O(1)

**Difficulty**

Very Easy

**All DMOJ subtasks accepted in:**

`0.62s, 10.52 MB`

### **CCC 14 S4 – Tinted Glass Window (ccc14s4)**

**Main idea / algorithm**

Use coordinate compression and a 2D difference array to compute total tinted area above threshold.

**Time complexity**

O(n log n + w × h), n = number of rectangles, w, h = compressed grid dimensions

**Space complexity**

O(w × h)

**Difficulty**

Medium–Hard

**All DMOJ subtasks accepted in:**

`1.34s, 93.17 MB` (PyPy3)

### **CCC 14 S5 – Lazy Fox (ccc14s5)**

**Main idea / algorithm**

Model distances between points and use dynamic programming to find the longest sequence of jumps satisfying distance constraints.

**Time complexity**

O(n²)

**Space complexity**

O(n)

**Difficulty**

Hard

**All DMOJ subtasks accepted in:**

`1.20s, 28.63 MB`
